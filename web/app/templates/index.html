Sample

スマホの Google マップからエクスポートしたロケーション履歴 JSON をアップロードすると、 ダークな地図の上を発光するトレイルが移動するムービーを生成します。 期間や早送りの度合いは自由に指定でき、カメラは移動範囲に合わせて自動でズームします。 「自宅圏の追加早送り」を有効にすると、長期滞在している拠点（自宅など）の周辺 50km は高速で流れ、そこから離れた旅行の部分がじっくり描かれます。 下は架空の旅程データ（大阪 → 飛行機 → 沖縄本島 海岸線ドライブの 2 日間）を 14 秒にしたサンプルです。

💻 位置情報をアップロードしたくない場合は、 GitHub のソースコード を手元の PC で実行すれば、データを一切外部に送らずに同じムービーを生成できます。

📱 ロケーション履歴 JSON の取得方法

  1. スマホの Google マップ を開く
  2. プロフィールアイコン → 設定
  3. タイムライン → タイムラインのエクスポート
  4. 書き出された location-history.json を下で選択
